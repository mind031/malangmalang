# 말랑말랑

찹쌀떡 친구들과 함께 두는 아이용 체스 게임입니다. 브라우저만 있으면 아이패드, 갤럭시, 아이폰, PC에서 모두 돌아갑니다.

## 할 수 있는 것
- 같이 두기: 한 기기로 둘이서 (마주 보기 모드)
- 온라인으로 두기: 방 번호 네 자리로 각자 기기에서 (가입 없이 두 기기를 직접 연결)
- AI랑 두기: 아기 떡 · 꼬마 떡 · 보통 떡 · 똑똑 떡 · 대장 떡 5단계
- 배우기 도움: 갈 수 있는 칸 표시, 체크 경고, 무르기, 힌트, 말 설명
- 특별 규칙 켜고 끄기: 캐슬링, 앙파상, 폰 승급 고르기
- 한 수 생각 시간(1·3·5분), 효과음, 떡 색·판 색 고르기
- 프로필별 승패 기록과 AI 단계별 도장

## 파일
- `index.html`: 이 파일 하나만 열면 바로 게임이 됩니다 (깃허브 페이지가 보여 주는 파일, `dist/index.html`과 같음)
- `src/`: 원본 코드 (`engine.js` 규칙과 AI, `app.js` 화면, `style.css`, `index.html`)
- `build.py`: `src`를 합쳐 `dist/index.html`을 만듭니다
- `test/engine.test.js`: 규칙 검증 (`node test/engine.test.js`)

기록은 각 기기의 브라우저에만 저장되고 다른 곳으로 보내지 않습니다. 온라인 대결은 PeerJS 공개 연결 서버로 두 기기를 찾아 이은 뒤 기기끼리 직접 수를 주고받으며, 대국 내용은 어디에도 저장되지 않습니다.
